## Highlights

- **Multi-File Verilog / SystemVerilog Projects:** Upload multiple files, project folders (`webkitdirectory`), or `.zip` archives (`fflate`), plus page-wide recursive drag-and-drop. Manage files in **Project Explorer** (view, rename, replace, delete) and select any module as the active **Top Module**.
- **Multi-Directory `` `include `` Support:** `public/verilator/verilator-worker.js` preserves folder hierarchy in Emscripten MEMFS and passes `-I<dir>` flags for every project subdirectory.
- **4 Multi-File Example Projects:** SW-to-LED, Counter, 7-Segment Decoder, and 16×16 Matrix (`src/presets/exampleProjects.ts`).
- **High-Speed `SimulationEngine`:** React-decoupled, time-sliced cycle loop (`src/sim/simulationEngine.ts`) with rate presets (`1 Hz`–`100 kHz`, `Unlimited`), batch execution (`10`–`100k` cycles), Pause/Resume/Stop, and live `Cycle / Speed / Elapsed` telemetry.

## Stabilization Fixes Included

- **CRIT-03:** Disposed and nulled stale `FpgaRuntime` instances immediately on compile failure (`src/App.tsx`). Verified live on GitHub Pages (zero stale evaluation after induced syntax errors).
- **CRIT-02:** Downgraded regex-inferred `MISSING_MODULE`, `DUPLICATE_MODULE`, and `CIRCULAR_REFERENCE` diagnostics to `warning` (`src/project/projectModel.ts`) and replaced the regex reachability allowlist in `selectFilesForTop()` with a strict-ancestor denylist (`src/project/projectCompile.ts`) so `generate`/`` `ifdef `` submodules are never dropped and Verilator remains the source of truth.
