## Highlights

- **Wave Viewer Expansion (`src/components/SignalMonitor.tsx`, `src/config/uiPreferences.ts`):**
  - Added `Visible Signals ▼` selector (`24`, `48`, `96`, `All`; default `24`), persisted in `localStorage` (`web_fpga_sim_wave_visible_count_v1`) without altering `HardwareConfig` (`schemaVersion = 1`).
  - Added **Signal Count Indicator** (`Showing X of Y signals`).
  - Added **Independent Scroll Area** (`max-h-[540px] overflow-auto` with sticky `<thead>`) so expanding to `48`/`96`/`All` never grows or clips the page.
  - Added **Sticky Signal Labels** (`sticky left-0 z-10` with opaque row-matched backgrounds) during horizontal scroll.
  - Added **Alternating Rows** (`bg-slate-950` / `bg-slate-900/90`) and **High-Contrast Waveforms** (`#fbbf24` high `1` ~12.2:1, `#94a3b8` low `0` ~6.6:1, `#fb923c` rising/falling transitions ~9.0:1, plus `1`/`0` axis markers).
  - Changing visible count triggers zero Verilog recompilation, zero simulation restart, and zero waveform reset.
- **Warm FPGA Lab Theme (`src/App.tsx`, `src/components/ClockControls.tsx`, `src/components/BoardView.tsx`, `index.html`):**
  - Styled header (`Digital Logic Workbench` badge alongside existing branding), transport buttons (`Compile`, `Run`, `Pause`, `Step`, `Reset`), status banners, tabs, and board bench chrome in warm Amber / Orange / Slate with WCAG AA/AAA contrast.
  - Added persisted theme switcher (`FPGA Lab` default / `Classic`, stored in `web_fpga_sim_ui_theme_v1`).
  - **All hardware colors preserved untouched** (LEDs, 7-Segment displays, and 16×16 Matrix pixel themes).
